## 快速测试

1. 修改 build.gradle.kts 确保 `resConfigs` 包含中文：
```kotlin
android {
    defaultConfig {
        resConfigs("zh", "en")  // 添加中文支持
    }
}
```

2. 重新构建 APK：
```bash
./gradlew assembleRelease
```

## 注意事项

- 所有字符串资源已添加到 `values-zh/strings.xml`
- 应用会根据系统语言自动切换中英文
- 需要逐一修改 Kotlin 文件中的硬编码文本
- 建议使用 Android Studio 的 "Extract String Resource" 功能批量处理
